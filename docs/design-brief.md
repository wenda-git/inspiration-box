# 灵感果仓 · 设计交付清单

> 面向设计师的完整资产清单。小程序端的所有视觉素材按这份文档交付即可。

---

## 一、品牌基础

### 产品信息
- 中文名：**灵感果仓**
- 英文名：**Inspiration Box**
- Slogan：**每周一箱，为你而挑**
- 定位：AI 驱动的每周健康水果订阅小程序
- 气质参考：三顿半 / Oatly / 每日黑巧（干净、暖意、手工感、克制的俏皮）

### 色彩规范

主色板（来自当前代码，请严格沿用）：

| 名称 | HEX | 用途 |
|---|---|---|
| 主底 奶油米白 | `#FAF6EF` | 页面背景 |

## 二、交付总览

设计师需要交付的资产分 6 大块：

1. **Logo 和 App 标识** —— 品牌主 logo、启动图、小程序封面
2. **功能图标（Functional Icons）** —— 菜单、按钮、状态（SVG 线条图标）
3. **TabBar 图标** —— 底部导航的普通/激活两态（PNG 位图）
4. **水果产品图** —— 所有 SKU 的实拍/准实拍小图（PNG 圆形透明底）
5. **插画 / 装饰元素** —— 登录页 hero、付款成功页庆祝图、首屏背景
6. **启动 / 分享素材** —— 启动图、分享卡封面

每一节下面都给了格式、尺寸、数量、细节要求。

---

## 三、Logo 和 App 标识

### 3.1 主 Logo（品牌核心）

- **数量**：1 套（含横版、竖版、纯图形 3 种排列）
- **格式**：SVG + PNG，PNG 提供 `@1x @2x @3x` 三档
- **基础尺寸（最小可读）**：图形不小于 96×96 px
- **导出尺寸**（PNG）：
  - 横版 480×120 / 960×240 / 1440×360 px
  - 竖版 240×360 / 480×720 / 720×1080 px
  - 纯图形 200×200 / 400×400 / 600×600 px（透明底）
- **设计要求**：
  - 需要体现"盒子 + 水果 / 挑选 / 鲜"的意象
  - 主色限定抹茶绿 `#6B9E5F` + 可可豆色 `#2B2420`
  - 不要写实水果、不用 emoji 风
  - 几何简练，线条粗细 ≥ 2.5px @1x（避免在小尺寸下断笔）
  - 方案风格参考：三顿半 / RALF'S / 一条
- **使用场景**：
  - 登录页 hero 区中央
  - 付款成功页顶部
  - 分享卡左上角
  - 后续若做 App 图标需另起规格（见 3.2）

### 3.2 小程序图标（微信后台需要）

- **数量**：1 张
- **格式**：PNG，圆角由微信自动处理
- **尺寸**：144×144 px，透明底或品牌底色
- **要求**：用主 Logo 的"纯图形"简化版，不含文字

### 3.3 小程序分享封面

- **数量**：1 张
- **格式**：PNG/JPG
- **尺寸**：**5:4**，推荐 1000×800 px
- **要求**：
  - 产品核心意象（一盒水果 + slogan）
  - 必须出现"灵感果仓"中文名和 slogan"每周一箱，为你而挑"
  - 右下角留一片干净区域（微信会自动覆盖角标）
  - 分享出去在微信对话框里清晰可辨

## 四、功能图标（Functional Icons）

### 统一规范

- **格式**：SVG（优先）+ PNG 备份（@2x 72×72 px、@3x 108×108 px）
- **画布**：24×24 viewBox（和当前代码里所有 SVG 一致）
- **笔触**：
  - 描边 1.8 px，线端圆角 `stroke-linecap: round`，拐角圆角 `stroke-linejoin: round`
  - 不填充（`fill: none`），使用 `currentColor` 描边让 CSS 可换色
- **风格**：线条图标，简约、统一圆角，不要实心填充风格
- **命名**：小写 + kebab-case，如 `icon-box.svg`

## 五、TabBar 图标（微信小程序规定格式）

- **数量**：每个 tab 2 张（未激活 + 激活），共 3 个 tab × 2 = 6 张
- **格式**：PNG（微信要求）
- **尺寸**：**81×81 px**（微信规范）
- **颜色**：
  - 未激活：`#8F877F`（灰褐色）
  - 激活：`#6B9E5F`（抹茶绿）
- **Tab 列表**：
  - `tab-home-off.png` / `tab-home-on.png` —— 本周
  - `tab-chat-off.png` / `tab-chat-on.png` —— 反馈
  - `tab-user-off.png` / `tab-user-on.png` —— 我的

## 六、水果产品图（重点！替代 Emoji）

### 背景
当前代码数据库 `fruits.emoji` 字段里存的是系统 emoji（🫐🍎🍊...），只是临时占位。上线前必须替换成真实产品图。

### 规范
- **数量**：按当前 SKU 数 = 8 个，后续每新增一个 SKU 补一张
- **格式**：PNG 透明底
- **尺寸**：**480×480 px**（@2x 显示即 240pt，覆盖所有 `.fruit-avatar` 场景）
- **要求**：
  - **白色 / 透明背景**，主体居中，四周留白 8–10%
  - **写实风格**但有"产品精修"感（像电商主图那种），不是插画
  - 光源从左上来，柔和漫反射，不要硬阴影
  - 每张图视觉重量一致（比如蓝莓小可以放 3-5 颗一堆，苹果放一整个）
  - 饱和度适中，不要过度磨皮/失真
- **命名**：`fruit-{code}.png`（code 对应数据库 `fruits.code`），如：
  - `fruit-blueberry_yunnan.png`
  - `fruit-apple_fuji.png`
  - `fruit-grapefruit_red.png`
  - `fruit-kiwi_gold.png`
  - `fruit-strawberry_danong.png`
  - `fruit-pomegranate_tunisia.png`
  - `fruit-orange_gannan.png`
  - `fruit-cherry_yantai.png`

### 额外交付
- **1 张"通用默认图"**：`fruit-default.png`，用于后台新录入但还没配图的 SKU 做 fallback（画一个中性水果剪影）

## 七、插画 / 装饰元素

### 7.1 登录页 Hero 插画

- **数量**：1 张
- **格式**：SVG（推荐）或 PNG 透明底
- **尺寸**：750×560 px（@2x，即小程序设计稿 375×280 pt）
- **要求**：
  - 主体：一个打开的"水果盒"，里面有 3-5 种水果探出来
  - 风格：扁平插画 + 少量高光，有温度但不幼稚
  - 主色抹茶绿 + 桃橙点缀，背景透明
  - 略带俏皮但克制（不要卡通脸孔）
  - 参考：三顿半小程序、LemonBox 登录页

### 7.2 付款成功页庆祝图

- **数量**：1 张
- **格式**：SVG 或 PNG
- **尺寸**：600×600 px
- **要求**：
  - 一枚"订阅成功"的徽章/奖牌感
  - 中间一个大勾或"VIP / 订阅中"字样
  - 四周散落少量水果、叶片、confetti 碎片（静态，不做动效）
  - 主色抹茶绿 + 金色点缀（不要纯金，用 `#F2C14E` 奶油黄）

### 7.3 空状态插画（3 张）

- **尺寸**：500×400 px 透明底
- **清单**：
  - `empty-orders.svg` —— "还没订单" 空状态（一个空盒子 + 一片叶子）
  - `empty-feedback.svg` —— "还没反馈" 空状态（一支铅笔 + 便签）
  - `empty-weekly-loading.svg` —— 配单生成中（抽象的圆 + 辐射，AI 感）
- **要求**：单色线稿或浅色块，不抢眼，陪伴型

### 7.4 首屏（weekly 页）背景装饰

- **数量**：1 套（3–4 个水果剪影 PNG，可自由组合）
- **格式**：PNG 透明底
- **尺寸**：每个 300–400 px 见方
- **清单**：蓝莓剪影、柑橘剪影、苹果剪影、叶子剪影
- **要求**：
  - 低饱和度（opacity 25% 左右），纯装饰
  - 代码里会定位到 hero 卡背景做"漂浮水果"效果
  - 需要线条简洁能识别即可，不要精致细节（会被缩小 + 降透明度）

## 九、交付方式

- 所有 SVG 通过 figma 交付 + 导出一份 zip 给工程
- 所有 PNG 交付 @1x @2x @3x 三档（如只能给一档，给 @3x）
- 命名和文档里表格完全一致，方便工程直接替换
- 建议一个 figma 文件里分 6 个 page（对应 6 大块）

---

## 十、设计师不确定时的回退规则

- **颜色**：如果拿不准，用抹茶绿 `#6B9E5F` 和可可豆色 `#2B2420` 两色黑白稿先交付
- **描边 vs 填充**：功能图标一律描边（参考当前 SVG），插画可以填充
- **emoji**：**整个项目禁止使用 emoji**（包括但不限于 🍎💡✓🎁 这种），一律用 SVG 替代

## 附录 · 设计哲学一句话

> **"一盒水果刚从阳光里摘回来，不是 App 推销给你的。"**
> 视觉要有体感、温度、克制的精致，不要科技感、不要广告感、不要过度卡通。
